# Store Sales Dashboard - Excel & SQL

## 📊 Project Overview
Analyzed retail store sales data to track KPIs, monthly trends, and category performance. Built interactive dashboard for business decision making.

## 🛠️ Tools Used
- Excel: Data Cleaning, VLOOKUP, Pivot Tables, Charts, Slicers
- SQL: JOINs, GROUP BY, Window Functions
- Skills: Data Cleaning, KPI Tracking, Business Insights

## 📈 KPIs Tracked
- Total Sales & Profit
- Monthly Sales Trend
- Top 5 Products by Sales
- Sales by Category & Region

## 🔍 Key Insights
- Identified top performing product categories driving 70% revenue
- Found seasonal sales drop in Q2, suggested promotional strategy
- Cleaned 15% duplicate/inconsistent data
